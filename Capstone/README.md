## Run the assembler in VS Code

Open a terminal in this folder and run:

```powershell
python assembler.py Add.asm
python assembler.py Max.asm
python assembler.py Rect.asm
python assembler.py Pong.asm
python assembler.py Box.asm -o Box.hack
```

The assembler creates `<name>.hack` beside the input unless `-o` is supplied. Invalid instructions are reported as `Line N: Invalid instruction.` and the program returns a non-zero status without crashing.

## Preventing the “Missing 'CHIP' keyword” error

A `.tst` file is a test script, not an HDL chip. Do not use the simulator's **Load Chip** or HDL-file loader on `CPU.tst` or any other `.tst` file.

Correct workflow:

1. Open `C:\project folder\capstone\CPU.hdl` using **Load Chip** and confirm its content starts with `CHIP CPU {`.
2. Open the Hardware Simulator script runner and choose **Load Script** or **File > Load Script**.
3. Select `C:\project folder\capstone\tests\CPU.tst`.
4. Run the script with the simulator's Run command.
5. Repeat the script-runner step for Memory and Computer tests. Never rename `.tst` files to `.hdl` or place test scripts in the HDL load field.

The script's `load ../CPU.hdl` directive loads the HDL chip from the script. The `CPU.tst` file itself should only be consumed by the script parser.
